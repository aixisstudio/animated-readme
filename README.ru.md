##   Шаблоны подписей

```markdown
<img src="https://readme-typing-svg.herokuapp.com?font=Fira+Code&size=28&duration=3000&pause=1000&color=58A6FF&center=true&vCenter=true&width=600&lines=Security+engineer;Building+Snitch;Network+visibility+for+everyone" />
```

Парамы: `font`, `size`, `duration`, `pause`, `color`, `lines=a;b;c`, `center`, `vCenter`, `multiline`, `repeat`.

##   Волновые заголовки

```markdown
<img width="100%" src="https://capsule-render.vercel.app/api?type=waving&color=0:0d1117,100:1f6feb&height=200&section=header&text=aixisstudio&fontSize=50&fontColor=fff&animation=twinkling" />
```

Типы: `waving`, `venom`, `slice`, `rect`, `soft`, `rounded`, `cylinder`, `shark`, `transparent`. Анимации: `twinkling`, `fadeIn`, `scaleIn`, `blinking`.

##   Дополнительные графы вклада

**3D профиль**: `github-profile-3d-contrib` — генерирует изометрический SVG в ночное время
Змея: `platane/snk` — классическая анимация еды
**Метрика**: `lowlighter/metrics` — кухонно-чернильный SVG (языки, привычки, изокалендар)
Skyline: `github.com/skyline` — ваш год в качестве 3D-печатного города
